# Neural Networks and Deep Learning — Lecture Notes & Course Pack

## Stanford CS231n — Deep Learning for Computer Vision
**The gold standard for neural network and deep learning notes.**

**Interactive notes site (Markdown/HTML):** https://cs231n.github.io/

**GitHub repository (Markdown sources):** https://github.com/cs231n/cs231n.github.io

**Contents (all in Markdown):**

### Module 0: Setup
- Software setup
- Python/Numpy tutorial (Jupyter + Colab)

### Module 1: Neural Networks
- **Image Classification** — k-Nearest Neighbor, train/val/test splits, L1/L2 distances
- **Linear Classification** — SVM, Softmax, hinge loss, cross-entropy, L2 regularization
- **Optimization** — Stochastic Gradient Descent, analytic/numerical gradient
- **Backpropagation** — chain rule, real-valued circuits, gradient flow
- **Neural Networks Part 1** — architecture, activation functions, representational power
- **Neural Networks Part 2** — preprocessing, weight initialization, batch normalization, dropout
- **Neural Networks Part 3** — gradient checks, momentum, Adagrad/RMSprop, hyperparameter optimization

### Module 2: Convolutional Neural Networks
- **CNN Architectures** — Convolution/Pooling layers, AlexNet/ZFNet/VGGNet
- **Visualizing CNNs** — tSNE, deconvnets, fooling ConvNets
- **Transfer Learning** — Fine-tuning
- **RNN** — Recurrent Neural Networks
- **Transformers** — Transformer architecture

**Format:** Pure Markdown in the GitHub repo, rendered as a website. Ideal for quick reference and forking/customization.
