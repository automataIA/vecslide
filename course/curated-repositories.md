## How to search for more materials on GitHub

Useful queries in the GitHub search bar:

```
"lecture notes" "neural networks" extension:md
"course pack" "mathematical analysis" extension:pdf
"lecture notes" "machine learning" extension:md
"deep learning" "course notes" extension:md
"calculus" "lecture notes" extension:pdf
```

Replace `extension:md` with `extension:pdf` or `extension:tex` for other formats.
